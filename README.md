## Deskripsi Project
Website ini adalah portofolio pribadi modern yang dirancang untuk memperkenalkan identitas profesional saya sebagai mahasiswa Informatika. Fokus utama project ini adalah implementasi **Tailwind CSS** untuk desain yang responsif dan **Vite** sebagai workflow pengembangan yang cepat.

## Struktur Project (Track B)
Project ini mengikuti struktur standar Vite dengan penyesuaian untuk tugas kuliah:
- `index.html`: Struktur utama website dengan utility classes Tailwind.
- `vite.config.js`: Konfigurasi build tool dan integrasi plugin Tailwind CSS.
- `package.json`: Daftar dependensi (Vite, Tailwind) dan script perintah.
- `src/main.js`: Entry point JavaScript untuk mengimpor CSS dan logika interaktif.
- `src/style.css`: File stylesheet utama yang mengimpor core Tailwind.
- `public/`: Folder untuk aset statis seperti gambar/ikon.

## Teknologi & Fitur
- **Vite & Tailwind CSS 4**: Menggunakan versi terbaru untuk performa maksimal.
- **Responsive Navigation**: Navbar yang beradaptasi menjadi menu hamburger di perangkat mobile.
- **Modern Minimalist UI**: Skema warna biru/putih yang bersih dan profesional.
- **Interaktivitas JS**: Logika toggle menu mobile dan smooth scroll.
- **SEO Optimized**: Penggunaan tag semantik dan meta description.
