## 🚀 Key Features

- **📱 Responsive Layout**: Optimized display across mobile, tablet, and desktop devices.

- **👤 About Me Section**: Background information on education and development focus.

## 🛠️ Tech Stack

This project is built using **Track B (Vite + Tailwind CSS)**:

* **HTML5**: Semantic content structure for accessibility and SEO.
* **Tailwind CSS v4**: The latest utility-first CSS framework for modern and responsive design.
* **JavaScript (Vanilla)**: For interactive logic, navigation, and animations.
* **Vite**: A modern build tool for ultra-fast development performance.
* **Lucide Icons**: A lightweight and beautiful vector icon library.
